# Privacy Policy

The Desearch plugin sends your search requests to the Desearch API so it can return results.

## What the plugin sends
- The query text and tool options you set (for example sources or filters).
- Your Desearch API key, to authenticate the request.

Queries can contain personal data if you type it into them.

## What the plugin stores
The plugin does not store, log or share your queries, results or API key. Dify stores the API key as a secret credential.

## Where the data goes
Requests go over HTTPS to the Desearch API, operated by Desearch. Desearch handles this data, including API calls, queries and usage data, under its privacy policy: https://www.desearch.ai/privacy
